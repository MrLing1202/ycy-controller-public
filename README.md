# ⚡ YCY Controller

AI驱动的BLE设备智能控制引擎。

---

## 快速开始

```bash
cp .env.example .env
# 编辑 .env 填入BLE协议和AI模型配置

pip install -r requirements.txt
python run.py
```

浏览器打开 http://localhost:8080

---

## 功能总览

### 🤖 AI人格控制
- 多种AI人格 + 随机模式，每种有独特交互风格
- AI实时自主决策，智能调节设备节奏
- 自动安排休息，合理控制强度曲线

### 💬 AI对话
- 文字/语音对话，AI实时回应并调整设备
- 停止时AI会嘲讽、戏谑玩家

### 👍👎 反向反馈
- 点👍 → AI收回强度，边缘控制
- 点👎 → AI变本加厉

### 🎤 声音寸止
- 实时监听声音，智能判定临界状态并自动停止设备
- 精准区分人声与环境噪音，杜绝误触
- 渐变预警，非突然触发
- 微弱声音同样灵敏，适配各种环境
- 实时可视化 + 模拟测试模式
- 无需设备即可体验完整流程

### 🎵 音频跟随
- 设备随音乐节奏律动
- 支持系统音频捕获或本地文件
- 简单/高级双模式

### 🎲 随机模式
- 多通道随机跳变，参数可调

### ⏸ 停止按钮
- 永久停止 / 定时暂停后自动恢复
- 停止时AI嘲讽玩家

### 🎚️ 手动控制
- 三通道独立滑条，实时响应
- 非线性映射，低端更细腻

### 🎭 自动模式
- 6种预设节奏模式 + 自定义脚本

### ⏺ 录制回放
- 录制手动操作，一键回放或导出

### 📱 蓝牙直连
- 手机浏览器通过 Web Bluetooth 直连设备

### 🛡️ 安全保护
- 多重安全机制，断连即停
- 声音寸止强制中断 + 时长限制
